1 · Dashboard, the resting state

Two providers, two windows each. The bar reads first, the number confirms it, the countdown answers “when do I get it back”. Provider hue is the fill until a threshold flips it to warning amber or critical red — so a healthy screen is two colours and a stressed one shouts.

An unconfigured provider is never drawn — no greyed block, no “not set up” placeholder. 2 · Provisioning & connectivity

First boot, or any time WiFi is gone. The device never shows a blank screen: it tells you what it is doing and how to reach it.

2a · Setup mode (first boot)

AP · 192.168.4.1
SETUP MODE Join this hotspot networkTokenMeter-3F2A passwordkite-8841 then open 192.168.4.1

QR encodes WIFI:T:WPA;S:TokenMeter-3F2A;P:kite-8841;; — phones join with one tap; the captive portal opens the setup wizard automatically. SSID suffix = last two MAC bytes; the password is generated once and persisted (shown as illustrative pattern here, real QR from LVGL’s lv_qrcode).

2b · Booting / connecting

STA · connecting
Token Meter

5 · Connectivity state machine

What the device does when the network is not there. The web UI is reachable in every state except booting.

stateDiagram-v2
    [*] --> Boot
    Boot --> Provision : no WiFi creds in NVS
    Boot --> Connecting : creds found
    Provision --> Connecting : wizard saves creds
    Connecting --> Online : got IP + NTP
    Connecting --> Fallback : 3 × 30 s failed
    Online --> Fallback : link lost > 20 s
    Fallback --> Online : background STA retry (60 s) succeeds
    Fallback --> Connecting : new creds saved via portal
    Online --> Provision : factory reset
    state Provision {
        direction LR
        AP_only : softAP TokenMeter-XXXX + captive DNS
        LCD_2a : LCD shows QR + password
        AP_only --> LCD_2a
    }
    state Fallback {
        direction LR
        AP_STA : softAP + STA retry
        LCD_2c : LCD greyed + OFFLINE banner
        AP_STA --> LCD_2c
    }
    state Online {
        direction LR
        Poll : Claude 180 s / GPT 120 s, staggered
        LCD_1 : LCD dashboard
        Poll --> LCD_1
    }

6 · Tokens for the LVGL build

Everything the firmware theme file needs. Colours are RGB565-safe (checked on the ST7789’s 16-bit path); fonts are LVGL’s bundled Montserrat sizes so no font conversion is needed for MVP.
